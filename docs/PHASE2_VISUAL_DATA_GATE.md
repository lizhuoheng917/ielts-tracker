# Tracker 第二阶段首批：视觉系统与单词数据视图

## 本批完成范围

本批以单词记录页作为第二阶段的纵向样板，先建立后续页面可复用的视觉和数据展示契约：

- 统一亮暗主题的容器、状态、IELTS 四科、图表与插图语义色。
- 新增 `PageHeader`、`SectionHeader`、`MetricCard` 与 `DataToolbar`。
- 将卡片的悬浮抬升改为显式 `interactive` 行为，静态信息卡不再伪装成可点击控件。
- 单词记录支持搜索、分类、日期范围、四种排序、结果计数和每页 50 条分页。
- 桌面端使用语义表格和吸顶表头，手机和平板使用记录卡片。
- 空数据和无匹配数据都有代码矢量插图、解释与可执行操作。
- 补齐表单标签、开关状态、切换按钮状态和关键图标按钮的可访问名称。
- 修复统计页 AI 悬浮按钮被切页动画或手机底部导航遮挡，以及拖动后误触点击的问题。
- 预构建懒加载页面使用的 Base UI 子模块，避免开发环境首次切页触发依赖重载。

## 数据与发布影响

- `Frontend`: changed。
- `Backend`: reviewed-not-needed；仍使用原有浏览器本地 `WordRecord`，没有 Supabase 或同步契约变化。
- `Admin`: reviewed-not-needed；项目当前没有管理端，也没有新增远程可管理状态。
- `Deployment`: not-deployed；本批不提交、不推送、不部署。
- `Verification`: 完整门禁和浏览器验收通过后才可标记为 passed。

## 本批验收清单

- `npm run verify:release` 通过。
- 搜索、分类、日期和四种排序的纯函数测试通过。
- 5000 条单词记录只返回当前页 50 条，页数为 100。
- 1440px 桌面端显示表格；390px 与 320px 显示移动卡片布局且无横向溢出。
- 亮色与暗色主题下，数据工具栏、表格和空状态可辨识。
- 新增记录表单可通过标签定位；保存后桌面表格和移动卡片均显示记录。
- 无匹配筛选显示专用空状态并可清空筛选。
- 统计页 AI 按钮是 `body` 直属 portal，手机端位于底部导航上方并可打开反馈面板。
- Vite `--force` 冷启动后，首次进入设置页、切换主题和继续切页没有 console error 或 warning。
