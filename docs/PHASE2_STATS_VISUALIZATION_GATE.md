# Tracker 第二阶段第三批：统计可视化与口径统一

## 本批完成范围

本批把第二阶段的页面、指标卡与插图规范扩展到数据统计，并让首页报告与统计页共享同一套数据口径：

- 新增共享 `ChartCard`、`ChartRangeControl` 与 `ChartLegend`，统一图表标题、说明、图例、固定响应式高度、空状态插图和无障碍标题关联。
- `Stats` 增加全局 7 / 30 / 90 天切换，背词趋势、学习时长、四科平均分和单词分类四张图共享同一个闭区间。
- 增加区间学习单词、学习时长、练习次数和完成计划四项概览；连续天数、最长连续天数和累计活跃天数改用共享指标卡。
- 图例、提示框、坐标轴、科目颜色和分类颜色统一使用亮暗主题语义令牌。
- 图表无数据时继续使用已有代码矢量插图；分类超过 8 类时保留前 7 类并准确合并为“其他”。
- `Dashboard` 今日、本周和本月报告与 `Stats` 复用同一个汇总函数；本周、本月均明确统计到今天，不读取未来记录。
- `Dashboard` 最近活跃度修正为完整 5 周网格，星期标题、未来占位和今天高亮保持正确。

## 统计契约与正确性

- 7 / 30 / 90 天都采用 `[today - (N - 1), today]` 的本地日期闭区间，日期首尾都计入。
- `PracticeRecord.duration` 仍持久化为分钟，`TimerRecord.duration` 仍持久化为秒；展示前先把所有记录汇总为精确秒数，再做一次分钟换算。
- 每日时长柱图使用精确秒数绘制，提示框按小时、分钟或秒显示；概览和首页报告在总和后取整，避免多条短计时被逐条舍弃。
- 四科平均分只统计所选区间内有有效评分的模考；分类占比只统计所选区间内的背词记录。
- 两个页面的热力图共享 `0 / 1–2 / 3–5 / 6–8 / 9+` 活跃等级。
- 累计活跃天数只统计有效、非未来且活动值大于零的日期，并明确其语义是累计学习事件，而不是当前记录反算结果。
- AI 学习数据显式区分模考分钟和计时秒数/分钟，避免报告把计时数据误读为分钟。
