# Tracker 第二阶段第四批：核心页面视觉收尾

## 本批目标

本批完成第二阶段的视觉收尾，把首页、学习日记、成就中心和设置页接入同一套页面标题、紧凑指标组、区块标题、状态色与代码矢量插图，并专项处理页面切换、低动态偏好、键盘焦点和长列表渲染。

## 已完成范围

### Dashboard

- 首页最终重排为“紧凑欢迎与打卡卡片 → 今日指标 → 轻量备考工具 → 待办与活跃度 → 成长回顾”，降低同级卡片过多造成的浏览负担。
- 根据实机反馈恢复紧凑卡片式欢迎区，并删除重复且占据大幅首屏空间的 `TODAY'S FOCUS` 主卡；空待办、空日记和空成就继续使用共享插图系统。
- 考试倒计时和 AI 学习建议保留为轻量工具卡，不再与首页主任务争夺视觉层级。
- 今日背词、学习时长、连续学习和计划完成融合为一个 `MetricGroup`，避免四张独立卡片平均争夺注意力。
- 待办按钮不再依赖整卡点击或 hover；完成状态、详情入口与进度条补齐键盘焦点和 ARIA 语义。
- 活跃度继续使用与 Stats 一致的强度函数和语义色；报告仍复用同一汇总口径。
- 大量日记时，最近日记由排序改为单次扫描；今日执行记录先构建映射，避免计划逐项重复查找。

### Diary

- 接入 `PageHeader`、`MetricGroup`、`SectionHeader`、`DataToolbar`、`DataPagination` 和 `EmptyState`。
- 增加内容搜索、心情筛选、日期排序，以及每页 50 条的前端分页。
- 空数据库与筛选无结果分别呈现；编辑、删除操作在触控和桌面上都始终可见。
- 表单标签、心情选择、按钮焦点和删除确认语义补齐；移除列表 stagger 动画。

### Achievements

- 重做等级主卡、经验进度、规则说明，以及已解锁和待解锁徽章墙。
- 320px 为单列徽章，较宽手机转为双列，桌面扩展到四列。
- 进度条、徽章状态和列表补齐无障碍语义；移除 shimmer、stagger 和 hover scale。
- 显示层对异常负 XP 做零值保护，不修改浏览器中保存的原始数据。

### Settings

- 重组为考试目标、界面与主页、AI 连接、备份与数据管理四个区块。
- 主题改为原生三态单选控件，可使用键盘方向键切换；开关使用共享 `Switch`。
- API Key 显隐、连接状态、导入按钮和危险操作补齐焦点、状态播报和触控区域。
- 移除连接检测 pulse；保持现有 Store、备份版本、CSV、AI 接口与清空逻辑不变。

### 页面切换与共享组件

- 路由切换动效缩短为 160ms 纯透明度过渡，避免位移动画让固定元素抖动。
- 路由变化后更新页面标题、滚动到顶部并把焦点交给主内容区；保留跳过导航入口。
- `prefers-reduced-motion: reduce` 会关闭路由、加载、列表和控件动画，并清除动画/过渡延迟。
- 移除会覆盖所有控件的全局按钮缩放规则；共享按钮继续提供局部按压反馈。
- 重复汇总指标统一使用单卡多指标的 `MetricGroup`；320px 下三列指标会隐藏非必要图标并完整换行标签，避免截断。
- 弹窗遮罩对比度增强，默认关闭按钮改为中文可访问名称。

## 2026-08-01 卡片注意力预算复核

### 使用原则

- 大卡只保留给当前主任务、关键进度或需要足够绘图区的数据图表；普通汇总数字不再各占一张卡。
- 无数据图表使用紧凑高度；有数据时才恢复完整绘图区，避免空状态比有效内容更抢注意力。
- 表单与记录容器可以保持完整宽度，但使用中性表面，不与主操作、等级进度或学习结果争夺强调色。

### 实施结果

- Dashboard 四张独立概览卡融合成一个指标组；538px 下四项单行呈现，整个指标组为 107px 高。热力图限制单元格尺寸并取消与待办卡等高拉伸。
- Plans、Words、Practice、TimerPractice、Stats、Diary 的重复 KPI 卡全部融合为紧凑指标组；TimerPractice 调整为“核心计时器 → 次级指标 → 历史记录”。
- Stats 无数据图表使用紧凑高度，真实趋势、分布和能力图仍保留必要绘图区；Words 日历限制最大宽度，避免宽屏无限放大。
- Achievements 保留唯一的等级进度 Hero，将 XP 与徽章进度合入 Hero，并把 XP 规则改为默认折叠的说明区。
- Settings 首屏移除四张非任务型数据卡，将同样信息下移到“备份与数据管理”；考试、外观、AI 和数据操作仍按任务分组。

### 验证结果

- 全部九个路由在 320px、390px、538px 和 1440px 下无横向溢出。
- 320px 下所有紧凑指标的标签和数值均完整可读，没有截断；538px 首页四项概览仅占一行。
- 页面 console 没有 error 或 warning；卡片收敛未改变学习记录、备份、AI、计划或成就数据契约。
