# Tracker 第二阶段第二批：响应式练习与计划数据视图

## 本批完成范围

本批把第二阶段首批在单词页建立的数据视图规范扩展到模考、计时练习和学习计划：

- `Practice` 支持按科目独立搜索、日期筛选、六种排序、结果计数和每页 50 条分页。
- `TimerPractice` 支持搜索、科目与日期筛选、四种排序、结果计数和每页 50 条分页。
- `Plans` 支持搜索、状态、分类与频率筛选、四种排序、结果计数和每页 50 条分页。
- 三个页面统一使用页面标题、指标卡、数据工具栏、桌面语义表格、移动记录卡和专用空状态。
- 表单标签、选中状态、图标按钮名称、删除确认和移动端操作区完成可访问性整理。

## 正确性加固

- 雅思分数滑轴只允许“未评分”或 `1–9` 的半分档，提交边界也会归一化，不再可能保存 `9.5`。
- 模考页切换听、说、读、写科目后，原科目的搜索、日期、排序和页码状态保持不变。
- 计划表单只创建可执行的每日或每周计划；每周计划必须至少选择一天。
- 历史 `custom` 计划仍可显示和筛选，编辑时会明确提示并转换为受支持的频率。
- AI 生成的每周计划缺少星期时使用当天作为安全兜底，避免产生永不出现的待办。
- 计时停止后保留待保存场次，关闭记录框仍可继续填写；只有保存成功或明确丢弃才清除。
- 计时记录未修改分钟输入时保留原始秒数，只改备注不会把精确时长改写为整分钟。
- Timer XP 在新增、改长、改短和删除记录时按同一规则补差额，避免记录与等级数据分叉。

## 数据与发布影响

- `Frontend`: changed；页面、共享组件、筛选工具和浏览器本地记录生命周期有调整。

- `Deployment`: not-deployed；本批保持本地实现，没有提交、推送或部署。
